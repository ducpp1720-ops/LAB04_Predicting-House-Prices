# Lab 04 — PyTorch MLP Regression: Predicting House Prices

## FINAL STATUS: READY FOR SUBMISSION

This repository implements the Lab 04 requirement **Multilayer Perceptron Regression: Predicting House Prices** with PyTorch, using the real California Housing train/test CSVs. The project includes EDA, leakage-safe preprocessing, PyTorch training, baseline comparison, evaluation artifacts, tests, CLI prediction, and GitHub Actions reproducibility.

## 1. Objective

Predict `median_house_value` from eight California Housing input features with a PyTorch MLP and compare the result with Linear Regression, Decision Tree Regression, and Random Forest Regression.

## 2. Dataset

- Train: 17,000 rows
- Official test: 3,000 rows
- Columns: 8 input features + `median_house_value`
- No synthetic fallback
- GitHub Actions validates the exact schema, row counts, and missing-value condition before training

Features:

`longitude`, `latitude`, `housing_median_age`, `total_rooms`, `total_bedrooms`, `population`, `households`, `median_income`

Target: `median_house_value`

## 3. Required workflow implemented

1. EDA: shape, dtypes/info, missing values, duplicates, descriptive statistics, distributions, correlation and IQR outlier inspection.
2. `train_test_split(test_size=0.2, random_state=42)` on the official training CSV.
3. Official test CSV remains untouched until final evaluation.
4. `StandardScaler` is fitted only on the training partition.
5. PyTorch tensor dataset and `DataLoader` with batch size 32.
6. `HousePriceMLP`: **8 → 32 → 16 → 1**, ReLU hidden layers and linear output.
7. Adam + MSELoss, learning rate 0.001, 100 epochs, seed 42.
8. Training/validation loop uses `model.train()`, `model.eval()` and `torch.no_grad()`.
9. Best validation checkpoint is restored before final test prediction.
10. Evaluation with MAE, MSE, RMSE and R².
11. Comparison with Linear Regression, Decision Tree Regression and Random Forest Regression.
12. Model, scaler, predictions, metrics and figures are saved under the repository.
