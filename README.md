# Lab 04 — PyTorch MLP Regression: Predicting House Prices

## 1. Objective

Implement a **Multilayer Perceptron (MLP) regression model in PyTorch** to predict `median_house_value` from the California Housing dataset. The project also compares the MLP with Linear Regression, Decision Tree Regression, and Random Forest Regression.

## 2. Dataset

The project uses the real California Housing train/test CSV files used in the Google MLCC sample-data workflow. The documented dataset contains 17,000 training rows and 3,000 test rows with 8 input features plus `median_house_value`. citeturn3search4turn3search6

### Features

- `longitude`
- `latitude`
- `housing_median_age`
- `total_rooms`
- `total_bedrooms`
- `population`
- `households`
- `median_income`

Target: `median_house_value`

**No synthetic fallback is used.** If the real CSVs are absent, training stops with an explicit error.

## 3. Required workflow

1. EDA: shape, info, missing values, duplicates, descriptive statistics, distributions, correlation and outlier inspection.
2. Split the official training CSV into train/validation using `test_size=0.2, random_state=42`.
3. Keep the official test CSV untouched until final evaluation.
4. Fit `StandardScaler` on training data only; transform validation/test with the fitted scaler.
5. Build PyTorch `Dataset`/`DataLoader`.
6. Train `HousePriceMLP`: `8 → 32 → 16 → 1`, ReLU hidden layers, linear regression output.
7. Use Adam + MSELoss, batch size 32, learning rate 0.001, 100 epochs, seed 42.
8. Evaluate with MAE, MSE, RMSE and R².
9. Compare against Linear Regression, Decision Tree Regression and Random Forest Regression.
10. Save the model, scaler, metrics, predictions and figures.
