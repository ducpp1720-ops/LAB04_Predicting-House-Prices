# Lab 04 Final Report — California Housing Price Regression

## 1. Problem

Build a PyTorch Multilayer Perceptron regression model to predict `median_house_value` from eight California Housing features.

## 2. Data

The project uses the real Google MLCC California Housing train/test CSVs: 17,000 training rows and 3,000 official test rows, with 8 input features and one continuous target.

## 3. Preprocessing

The official training CSV is split into 80% training and 20% validation with `random_state=42`. `StandardScaler` is fitted only on the training partition and then applied to validation and official test data.

## 4. MLP architecture

```text
Input: 8
  ↓
Linear(8, 32)
  ↓
ReLU
  ↓
Linear(32, 16)
  ↓
ReLU
  ↓
Linear(16, 1)
```

Training configuration: Adam, MSELoss, learning rate 0.001, batch size 32, 100 epochs, seed 42, CPU/CUDA support.

## 5. Evaluation

The pipeline reports MAE, MSE, RMSE and R² and compares the MLP with Linear Regression, Decision Tree Regression and Random Forest Regression. Actual values are generated by `src/train.py` and stored under `results/`.

## 6. Evidence

The repository contains the source code, EDA notebook, generated metrics tables, prediction table, learning curve, actual-vs-predicted plot, model comparison plot, saved model, saved scaler and automated tests. GitHub Actions validates the real dataset and reproduces the training pipeline.
